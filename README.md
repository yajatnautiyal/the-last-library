# The Last Library

A fictional digital archive from the year 2095, built with only HTML, CSS and Bootstrap.

**Live site:** https://yajatnautiyal.github.io/the-last-library/

![The Last Library](assets/images/hero.png)

## About

The Last Library is a frontend concept project. In the story, most of human knowledge has been lost, and a vault called Archive Node 01 preserves what is left. All records and events are fictional.

## Features

- Dark, cinematic design with gold accents
- Archive cards, featured record and timeline
- Access request form
- Responsive layout for phones and desktops
- CSS-only animations

## Built with

- HTML5
- CSS3
- Bootstrap 5

## Run it locally

Download or clone the repo and open `index.html` in your browser.
